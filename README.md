# astrbot_plugin_number_bomb

群聊数字炸弹（猫娘文案）：开局随机炸弹、猜大/小缩区间、轮流猜数；回合超时催促后强制引爆；积分魔法护盾；管理员 `/拆弹`。

## 指令

| 指令 | 谁可用 | 说明 |
|------|--------|------|
| `/数字炸弹` | 全员 | 开局，默认 0～100 |
| `/数字炸弹 <N>` | 全员 | 开局，范围 0～N |
| `/数字炸弹 状态` 或 `/数字炸弹状态` | 全员 | 当前区间 / 轮到谁 / 催促进度 |
| `/数字炸弹 积分` 或 `/数字炸弹积分` | 全员 | 查看自己的积分 |
| `/数字炸弹 帮助` 或 `/数字炸弹帮助` | 全员 | 玩法说明书 |
| `/拆弹` | **仅管理员** | 强制拆除 |

对局中发送**纯整数**（且在当前区间内）= 加入或猜测。

## 规则摘要

1. 开局 `bomb = randint(0, N)`
2. 猜 `g < bomb` → `low = g+1`；`g > bomb` → `high = g-1`；相等 → BOOM
3. `low == high` → 下家被迫踩雷（同样发惩罚提示）
4. 回合超时（默认 **60s**）催促，满 **2** 次 → 当前玩家强制引爆
5. 等待第二人加入超时（默认 600s）→ 取消本局
6. 中途加入只入队排队，**不插队猜数**，不重置当前回合计时
7. 爆炸结果与惩罚提示**分两条**发送
8. **积分**：真实爆炸时，未踩雷的参与者各 +1（持久化）
9. **魔法护盾**：积分 ≥ `shield_cost`（默认 5）时踩雷自动扣分抵消炸弹并提示剩余积分；不够则不提积分
10. **结算**：`hit`/`no_safe`/`timeout` 均从总池抽 meme；等图生成后发两条——①爆炸文案+图 ②请输家/赢家惩罚；护盾抵消单独一条说明剩余积分
11. `group_blacklist` 内的群号完全不响应

## 配置

见 `_conf_schema.json`（WebUI 插件配置）。

惩罚表情包关键词池（可面板改）：

| 配置 | 含义 | 默认 |
|------|------|------|
| `punish_single_keywords` | 单图（仅失败者） | 发射、灰飞烟灭、红温…等 20 个 |
| `punish_dual_keywords` | 双图（胜利者+失败者） | 撅、抽、揍 |
| `meme_retry` | 倒退上限，`0`=整池都试 | 0 |
| `enable_punish_meme` | 总开关 | true |
| `enable_meme_generator` | 启用 meme_generator 解析未知词 | true |

解析顺序：**kimage 内置**（`发射`/`射`、`摸头`、`杀`、`撅`、`抽`）→ **meme_generator** 关键词/key。  
`min_images>=2` 当双图，否则单图；失败自动倒退；全失败只发文字。

积分文件：`data/plugin_data/astrbot_plugin_number_bomb/scores.json`
